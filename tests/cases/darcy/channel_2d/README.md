# Darcy 2D channel test

Compares an **explicit** Darcy problem (channel lumen cut out of the tissue mesh) with an **MPC** formulation (full square tissue + 1D channel line coupled by multi-point constraints).

Requires the `dev_MPC_OO` svMultiPhysics build with Darcy 1D / MPC support.

## Geometry and physics

- Domain: unit square `[0, 1]²`.
- Channel strip: `[0, 0.75] × [0.495, 0.505]` (length fraction 0.75, width 0.01, centered in `y`).
- Tissue permeability `1e-5`; 1D channel (MPC only) permeability `1e-3`.
- Time: 30 steps of `Δt = 0.001`.
- Channel pressure Dirichlet: ramp `0 → 1` over `[0, 0.02]`, then hold (`channel_pressure.dat`).
- Outer BCs: `P = 0` on right, bottom, and top; left is free.

```
  y=1  ┌────────────────────────────┐
       │                            │  P=0
       │         tissue             │
  y≈0.5├──────────────┐             │
       │   channel    │             │
       ├──────────────┘             │
       │                            │
  y=0  └────────────────────────────┘
       x=0           x=0.75       x=1
                      P=0 on top/bottom/right
```

## Explicit vs MPC

| | Explicit | MPC |
|---|---|---|
| Tissue mesh | Square with channel **cut out** | Full square |
| Channel | Boundary face `channel` on the cutout | 1D line mesh through the strip centerline |
| Coupling | N/A (Dirichlet on face) | `Coupling_method MPC` from fiber face → tissue |
| Inlet BC | Unsteady Dirichlet on `channel` face | Same unsteady Dirichlet on all 1D nodes (`fc_channel`) |
| Solver XML | `darcy_sim_explicit.xml` | `darcy_sim_mpc.xml` |
| Mesh dir | `explicit_mesh/` | `mpc_mesh/` |

In the MPC case, every node of the 1D channel is listed in `mpc_mesh/channel_nodes.txt` and used both for Dirichlet and for projection. Only one fiber face is allowed, so the lumen BC and MPC coupling share that face.

## Files

| Path | Role |
|---|---|
| `gen_mesh.py` | Build explicit, implicit dual-domain, and MPC meshes (Gmsh + VTK) |
| `darcy_sim_explicit.xml` | Explicit single-mesh Darcy run |
| `darcy_sim_mpc.xml` | Coupled tissue + fiber Darcy with MPC |
| `channel_pressure.dat` | Unsteady channel pressure history |
| `run_convergence.py` | Background-mesh refinement: MPC vs explicit |
| `convergence/` | Study outputs (`convergence_summary.csv`, `convergence.png`) |

Default mesh sizes in `gen_mesh.py`: background `h = 0.05`, channel / 1D spacing `0.005`.

## Generate meshes

```bash
cd Darcy/test_2d
python gen_mesh.py
```

This writes:

- `explicit_mesh/` — cutout tissue + `mesh-surfaces/channel.vtp`
- `mpc_mesh/` — full square + `channel.vtu` / `channel.dat` / `channel_nodes.txt`
- `mesh/` — optional dual-domain (tissue + filled channel) mesh if generated by the script main

## Run simulations

Point `svmultiphysics` at your `dev_MPC_OO` binary, for example:

```bash
SVM=/home/javiera/software/svMultiPhysics/dev_MPC_OO/build/svMultiPhysics-build/bin/svmultiphysics

$SVM darcy_sim_explicit.xml   # results: result_*.vtu in CWD (unless Save_results_in_folder is set)
$SVM darcy_sim_mpc.xml        # results: out_mpc/
```

Pressure is written as point data `MBF`.

## Convergence study

`run_convergence.py` varies the **background** tissue size `h ∈ {0.1, 0.05, 0.025}` while keeping the **1D channel** fixed (`h_channel = 0.005`, 151 nodes). For each `h` it:

1. Builds matching explicit and MPC meshes.
2. Runs both solvers.
3. Compares final tissue pressure outside the channel strip: samples exterior nodes from the explicit mesh and interpolates into the MPC field.
4. Also reports errors at five fixed probe locations (for quick pointwise checks):

   `(0.25, 0.60)`, `(0.50, 0.60)`, `(0.70, 0.60)`, `(0.50, 0.80)`, `(0.90, 0.50)`.

```bash
python run_convergence.py
```

Edit `mesh_sizes`, `svmultiphysics`, and probe list near the top of the script as needed. Outputs:

- `convergence/h_*/` — per-`h` meshes and `out_explicit/` / `out_mpc/`
- `convergence/convergence_summary.csv`
- `convergence/convergence.png` — max/mean `|P_MPC − P_explicit|` vs `h`

## Notes

- MPC needs `<Coupled> true </Coupled>` so fiber and tissue assemble in one system with projection constraints.
- The MPC constraint is applied to the updated primary field (inhomogeneous Dirichlet on the fiber); a homogeneous increment-only constraint leaves tissue at zero when the fiber Dirichlet is nonzero.
- Background refinement with a fixed channel is intentional: the study measures how well the projected coupling converges as the tissue mesh resolves the channel strip.
